2 · Clone it

        —
      

      
A clone is a byte copy of the original's whole Android data partition: the installed game, its downloaded assets and the account already logged into it. The original shuts down while it is copied — copying a running disk image gives you a torn one.

      

        
        
      

      

        
        
      

      

      
A clone carries the original's login too, so log out and into the next account inside each copy. Each one is a full copy on disk.

Updates

        —
      

      
The app pulls its own code from GitHub every time it starts, so reopening it is all it takes to be current. A private repo needs a read-only token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → only this repository, Contents: Read-only. The token is stored on this machine only and is never committed.
