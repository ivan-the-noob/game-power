1 · The original

—

Set this one up by hand: start it, log in, and download the game's asset packs. Everything you do here is what the clones inherit, so get it right once.

2 · Clone it

—

Each clone is a new instance that starts with the original's downloaded data already in place, so the packs are fetched once instead of once per instance. The original closes while it is copied.

A clone carries the original's login too, so log out and into the next account inside each copy. Each one is a full copy on disk: the same pack set across ten clones needs ten times the space.

Settings

Frame rate and render scale are the two settings an emulator calls Frame Rate and Resolution, applied to the game itself. Lower is cheaper and softer-looking. They take effect on instances started after you save.

Updates

—

The app pulls its own code from GitHub every time it starts, so reopening it is all it takes to be current. A private repo needs a read-only token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → only this repository, Contents: Read-only. The token is stored on this machine only and is never committed.
